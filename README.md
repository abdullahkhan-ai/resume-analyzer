# Resume Analyzer

A Resume Analyzer built using Python, Streamlit, OCR, and PDF parsing.

## Features
- PDF Upload
- Image Upload (PNG/JPG)
- OCR Text Extraction
- Resume Scoring
- Skill Detection
- Resume Summary
- Suggestions

## Technologies Used
- Python
- Streamlit
- PyPDF
- Pillow
- PyTesseract

## Run Locally

pip install -r requirements.txt

streamlit run app.py

## 📌 Overview

Resume Analyzer Pro is an AI-powered web application that analyzes resumes, evaluates ATS compatibility, calculates job-role match scores, and generates professional resume feedback.

The platform helps students, job seekers, and professionals understand how well their resume aligns with specific career roles.
